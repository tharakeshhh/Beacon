# Early Student Support System

A web-based tool that helps teachers and counselors identify students who may need extra support early, so they can step in before small problems grow.

## 🔗 Live Demo

**[Open the Early Student Support System](https://claude.ai/public/artifacts/a9602651-bb40-4a25-933f-560dca0cbab6)**

## Features

- Track student information and progress in one place
- Flag students who may be at risk (for example attendance, grades or behavior)
- Help staff plan and follow up on support actions
- Simple interface that runs directly in the browser, with no installation needed

## Getting Started

1. Download or clone this repository:
   ```bash
   git clone https://github.com/[your-username]/early-student-support-system.git
   ```
2. Open the project folder.
3. Double-click `index.html` to open it in your browser.
